# Contribuer

Ce projet est maintenu par une seule personne pour l'instant :
les **issues** sont la meilleure façon de contribuer (bugs, idées,
questions). Les **PRs externes ne sont pas acceptées encore**.

Mais toute idée née dans une issue peut devenir code : si elle est
retenue, elle sera implémentée dans une bornée et vous apparaîtrez
comme **origine dans le CHANGELOG**. Contribuer ici, c'est semer
des décisions, pas des diffs.

## Bien ouvrir une issue

- **Bogue** : commande exacte, sortie réelle (bloc de code), résultat attendu, version (`sdd --version`).
- **Idée** : le problème d'abord, la solution ensuite — une idée par issue.
- **Question méthodologique** (SDD, phases, waivers…) : tag `question` ; les meilleures deviendront la FAQ.

## Ce qui est hors périmètre

Les changements au format normatif de l'Annexe A (sorties `status`/`lint`)
sont des décisions du responsable — proposez, ne fork-patchez pas.
